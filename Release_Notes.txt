Version 7.2.1

* Hotfix for 7.2.0: neither PlayerSheet nor MonsterSheet could be opened - the console showed "The PlayerSheet Application class is not renderable because it does not implement the abstract methods _renderHTML and _replaceHTML"

* Fix: script/sheet/actor.js composes the base class via foundry.applications.api.HandlebarsApplicationMixin(foundry.applications.sheets.ActorSheetV2); PlayerSheet and MonsterSheet inherit it automatically. No other file changed functionally; the V13 context shape, templates and CSS of 7.2.0 remain untouched
* No world migration (systemMigrationVersion stays 7.0.1)

Version 7.1.9

* Root cause of the missing textures found: the css custom properties in the `:root` block (`--title-image`, `--title-color`, `--box-editable`, `--box-non-editable`, `--color-charBG`, `--color-npcBG`, `--chat-roll-border`) were declared as QUOTED strings (`--box-editable: "url(...)"`), which is invalid CSS - as raw values they never produced a background. * `setupConfigOptions()` rewritten defensively for V14: the stored values (`url(../asset/...)`) are rewritten to root-relative paths (`url(/systems/symbaroum/asset/...)`) before being applied as inline styles on `:root` (inline urls resolve against the page URL, not the stylesheet, and broke); each setting is applied in its own try/catch with a clear error log, so one broken value can no longer silently abort the whole loop
